## 🚀 Como usar

1. Abra seu executor favorito (KRNL, Fluxus, Wave, Delta, Synapse)
2. Copie e cole o link abaixo no executor:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/SEU_USUARIO/dedsec-panel/main/main.lua"))()
```

> Substitua `SEU_USUARIO` pelo seu usuário do GitHub após criar o repositório.
